# **App Name**: CampusConnect

## Core Features:

- Role Selection: Role Selection: Simulate user login with a dropdown to select from Student, CR, Media Club, IT Club, and Admin roles.
- Dashboard: Dashboard Display: Show a tailored dashboard based on the selected user role, displaying relevant queries, submission forms, or admin panels.
- Query Submission: Query Submission: Allow students to submit queries with title, description, and category. CR's can submit on behalf of their students
- Query Details: Query Details and Timeline: Display detailed information for each query, including a Point-of-Contact timeline showing the resolution steps and responsible roles.
- Admin Panel: Admin Panel: Provide an admin interface to view all queries, manage users, and simulate resolving or assigning queries.
- Role-Based Permissions: Role-Based Permissions: Render the UI conditionally based on the user role, restricting access to certain features and data.
- AI Resolver Suggestions: AI-Powered Suggestion Tool: Suggest potential resolvers (CR, Media Club, IT Club, Admin) for a query based on the content of the query. This tool analyzes the text and automatically suggests resolvers with the highest probability of resolving the query.

## Style Guidelines:

- Primary color: HSL(220, 60%, 50%) which converts to RGB hex #4775D1. This vivid, versatile blue evokes trustworthiness and efficient communication.
- Background color: HSL(220, 20%, 95%) which converts to RGB hex #F0F2F7. This desaturated light blue creates a clean, calming backdrop.
- Accent color: HSL(190, 50%, 40%) which converts to RGB hex #339999. This contrasting teal green provides highlights and calls to action, while still being aligned to the communications-centered intent of the app.
- Body and headline font: 'PT Sans', a humanist sans-serif, for a modern yet friendly feel, suitable for both headlines and body text. Note: currently only Google Fonts are supported.
- Use simple, clear icons to represent different query categories (IT, Media, Academic, etc.) and user roles. Icons should be consistent in style and size to maintain a professional appearance.
- Employ a clean, card-based layout for query listings. Each card should display essential information and a clear call to action. Prioritize readability and intuitive navigation throughout the app.
- Use subtle transitions and animations to provide feedback on user interactions and enhance the user experience. For example, use a smooth transition when expanding query details or submitting a form.
